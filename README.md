# 3 Norte 88 · Viña del Mar

Material de colocación: dos fichas HTML para compartir por WhatsApp, sin descarga ni registro.

- `index.html` — portada con enlace doble
- `inmueble.html` — venta del dominio
- `restaurante.html` — arriendo gastronómico

## Compartir

Portada: https://htmlpreview.github.io/?https://raw.githubusercontent.com/momolago/3norte88/main/index.html

Contacto de colocación: Hugo · hfavilla@nieny.cl

No incluir nombres de propietario, RUT de sociedades ni teléfonos personales en las fichas.

## Cómo mejorar

1. Editar los HTML (tipografía, fotos, copy, datos).
2. Abrir un pull request o enviar el archivo mejorado.
3. Probar en móvil: el destinatario abre el enlace en el navegador del teléfono.

Fotos van en `fotos/`. Los enlaces de Drive y Maps están en cada ficha.
